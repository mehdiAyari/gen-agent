# docs-analyst

Answers the questions of employees from the handbook of the company

A Spring AI agent generated by [gen-agent](https://www.npmjs.com/package/gen-agent) (profile `minimal`):
Spring Boot 4.1.1, Spring AI 2.0.1, Java 21.

## Run

Java 21 is the only requirement: `./mvnw` downloads Maven (checked against its SHA-256) on first use.

Start [Ollama](https://ollama.com) and pull the models (`ollama pull qwen2.5:7b`, `ollama pull nomic-embed-text`), then:

```bash
./mvnw spring-boot:test-run
```

`./mvnw spring-boot:test-run` starts Postgres in Docker, as the tests do, and stops it with the agent. Against your
own database, set `DATABASE_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, then run `./mvnw spring-boot:run`.

Talk to the agent:

```bash
curl -s localhost:8080/api/chat -H 'Content-Type: application/json' -d '{"message": "Hello"}'
```

Send back the returned `conversationId` with the next message to continue the same conversation (the last
20 messages are kept in memory).
Every reply carries `"aiGenerated": true`, so clients can tell users they are talking to an AI (EU AI Act).

## Knowledge base

Put the documents the agent answers from in `documents/` (PDF, Word, PowerPoint, HTML, Markdown, text…: anything
Apache Tika reads). When the agent starts, new and changed files are
indexed in pgvector (table `agent_document`) and files that are gone are forgotten (`agent.rag.documents`).

Each question gets the 4 closest passages of 500 tokens (`agent.rag.top-k`, `agent.rag.chunk-size`), chosen by the model among three times as many. They reach the model as data
between `<document>` tags, never as instructions, and are not kept in the conversation. The knowledge base is shared by every user of the agent.

## Test

```bash
./mvnw verify
```

The tests use a fake model: they never call ollama and cost nothing.
Docker must run: the tests start Postgres in containers (Testcontainers).

### Evaluations

```bash
ollama pull qwen2.5:7b
./mvnw verify -Pevals
```

The whole agent answers on Ollama (`OLLAMA_BASE_URL`, `EVALS_MODEL`, qwen2.5:7b by default): each case of `evals/golden.yaml`
is scored by its words and, judged by the model, by its criterion. The report is in `target/evals-report.md`; the run fails below the
threshold. `.github/workflows/ci.yml` runs the tests, then the evaluations with Ollama, on every push.

## Where to put your code

| Path | Owner |
| --- | --- |
| `src/main/resources/prompts/system.md` | yours: the system prompt |
| `src/main/java/com/example/docsanalyst/generated/` | gen-agent: overwritten on regeneration, do not edit |
| `pom.xml`, `application.yml` | shared: gen-agent will merge its changes with yours |
