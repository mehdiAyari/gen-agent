# gen-agent

> Describe your agent, get a production-ready Spring AI project.

gen-agent is an open source generator of [Spring AI](https://spring.io/projects/spring-ai) agents, in the spirit of JHipster:
describe your agent in an `agent.yaml` file (or answer a few questions) and get a complete Spring Boot project that compiles,
passes its tests and runs.

**Status:** V1 in progress — `minimal` profile, CLI only.

## Requirements (contributors)

Node 22+, pnpm, JDK 21 and Maven 3.9+ (for the end-to-end tests).

```bash
pnpm install
pnpm lint && pnpm typecheck && pnpm test
```
