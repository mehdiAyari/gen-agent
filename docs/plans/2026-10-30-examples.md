# Examples

Scope (2026-10-30): complete agents a visitor can read on GitHub, reproduce with the exact commands, and run on Ollama
without an API key.

## Decisions

|     | Decision                                                                                                                                                                                                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| X1  | `examples/<name>/` holds the generated project as gen-agent wrote it, plus the code written by hand afterwards (user-owned files only: tool handlers, system prompt, documents, evaluation cases).                                                                                                |
| X2  | Each example has a `make.sh` with the exact commands that produced it (`gen-agent new`, `import openapi`, `add tool`, `generate`…), run from an empty directory.                                                                                                                                  |
| X3  | Each README: what the example shows, how it was made (the commands of `make.sh`), what was written by hand (each file, and why), how to run it (`ollama pull`, then `./mvnw spring-boot:run` or `docker compose up`), what to try, a GIF recorded from a real run, the known limits of the model. |
| X4  | Ollama by default (`qwen2.5:3b`, `nomic-embed-text` for embeddings); the README shows the lines to change for OpenAI, Mistral or Anthropic.                                                                                                                                                       |
| X5  | CI: `make.sh` runs again in the end-to-end tests and every generated-owned file must equal the committed one (no drift); each example passes `./mvnw verify` with its hand-written code. A regeneration never touches the user files: the separation of ADR 0001, shown on real code.             |
| X6  | GIFs: terminal ones with asciinema and agg, browser ones (chat page, Grafana) with Playwright; recorded against Ollama on this machine, short (under 40 seconds), no personal data.                                                                                                               |
| X7  | The root README and the gallery of the web generator link to the examples.                                                                                                                                                                                                                        |

## The examples, in order

1. **petstore-assistant** (`minimal`): the public Petstore API imported from its OpenAPI spec; the agent finds pets by
   status and by id. Hand-written: the system prompt. GIF: import, generate, run, a question answered with a real API
   call.
2. **hr-assistant** (`standard`): Keycloak sign-in, conversations in Postgres, a Java tool that books a day off in a
   table of its own (Flyway migration written by hand) after the employee approves it in the chat page, and a tool that
   lists the days off left. GIF: chat page, sign-in, a request, the approval buttons.
3. **docs-analyst** (RAG): a documents folder with an original, fictional company handbook (Markdown and PDF), admin
   uploads, answers grounded in the passages, "I don't know" outside them, a reference set of evaluation cases.
   GIF: questions answered from the handbook, one refused, `./mvnw verify -Pevals` report.
4. **bank-desk** (`production`): personal data masked (an IBAN given to a transfer tool that waits for approval),
   prompt injection refused, a fallback model, kill switches, the Grafana dashboard, the Helm chart. GIF: the model
   sees `[IBAN_1]` while the tool gets the real one, an injection refused, the dashboard.

Each example is one delivery: built, tried for real on Ollama, recorded, committed.
